# MediCare: от архива до APK на телефоне

В архиве две папки:

- `backend/` — сервер (то, что работает в интернете и «общается» с ИИ);
- `app/` — само приложение для Android (из вашего `config.zip`), уже с новым дизайном и исправлениями.

Ваши исходные файлы остались у вас, ничего не потеряно. Новые файлы можно просто положить поверх старых.

---

## 1. Как работает backend (простыми словами)

Представьте ресторан. Приложение на телефоне — **гость**. ИИ Claude — **повар** на кухне. Backend — **официант**.

- Гость не ходит на кухню сам: у него нет ключа от неё. Ключ от повара (`ANTHROPIC_API_KEY`) лежит **только у официанта**, на сервере. Если бы он был в приложении, любой мог бы его достать из APK и тратить ваши деньги.
- Приложение отправляет официанту вопрос, а тот передаёт его повару и приносит ответ.
- Официант ещё и охранник: проверяет «пропуск» устройства, ограничивает число вопросов (6 в минуту, 100 в день на телефон) и сам распознаёт слова вроде «боль в груди», чтобы сразу сказать «звоните 112», даже если ИИ недоступен.

Всё, что вам нужно сделать с сервером: **один раз запустить его на сайте Railway и вписать два секрета**. Писать код на Python не требуется.

Совместимость приложения и сервера я проверил по коду: адреса `/api/v1/register` и `/api/v1/chat`, формат запроса и ответа, коды языков `ru/en/hy` и формат `install_id` совпадают.

## 2. Запуск backend на Railway

**Что понадобится:** аккаунт GitHub, аккаунт Railway (railway.com), ключ Anthropic API (console.anthropic.com).

1. **Ключ Anthropic.** В console.anthropic.com создайте API-ключ (начинается с `sk-ant-`). Сразу зайдите в настройки лимитов и **поставьте месячный лимит расходов** (например, 10–20 $). Это ваша защита от неожиданного счёта.
2. **Секрет сервера.** Придумайте длинную случайную строку, минимум 24 символа, лучше 40+ (латинские буквы и цифры; можно создать в менеджере паролей). Это `SERVER_SECRET`. Без него сервер намеренно не запустится.
3. **GitHub.** Создайте новый репозиторий `medicare-backend`. Загрузите в него **содержимое папки `backend/`** (кнопка *Add file → Upload files*; перетащите файлы и папки `app`, `tests`, а также `Dockerfile`, `railway.json`, `requirements.txt` и остальные). Файла `.env` в репозитории быть не должно.
4. **Railway.** *New Project → Deploy from GitHub repo* → выберите `medicare-backend`. Railway сам найдёт `Dockerfile`.
5. Вкладка **Variables** → добавьте:
   - `ANTHROPIC_API_KEY` = ваш ключ `sk-ant-...`
   - `SERVER_SECRET` = ваша длинная строка
   - `APP_KEY` **не добавляйте** (так проще; см. раздел 7).
   - Volume подключать **не нужно**.
6. **Settings → Networking → Generate Domain.** Получите адрес вида `https://что-то.up.railway.app`.
7. **Проверка.** Откройте в браузере `https://что-то.up.railway.app/health`. Должно быть: `{"status":"ok","ai_configured":true}`.
   - `ai_configured:false` — не вписан или неверен `ANTHROPIC_API_KEY`.
   - Деплой «упал» — почти всегда не задан `SERVER_SECRET` (или он короче 24 символов).

## 3. Вписать адрес сервера в приложение

Откройте `app/config.py` и в строке `API_URL = ""` впишите ваш адрес **без слэша в конце**:

```python
API_URL = "https://что-то.up.railway.app"
```

Это нужно сделать **до сборки APK**: на телефоне нет переменных окружения, адрес берётся только из этого файла. Если оставить пусто, помощник скажет, что сервер не настроен.

## 4. Посмотреть дизайн на компьютере (по желанию, но очень советую)

Так можно увидеть приложение за минуту, не дожидаясь сборки APK.

1. Установите Python 3.11 или 3.12 с python.org (при установке отметьте **Add Python to PATH**).
2. Дважды щёлкните `app/run_on_pc.bat`. В первый раз он скачает нужные библиотеки (несколько минут), потом откроется окно приложения.
3. На компьютере не работают фоновые напоминания, голосовой ввод и озвучка. Это нормально, они только на телефоне.

Если что-то выглядит не так, пришлите мне скриншот и текст ошибки из чёрного окна, и я поправлю.

## 5. Сборка APK в облаке (без Linux и без установки Android Studio)

1. На GitHub создайте второй репозиторий `medicare-app` и загрузите в него **содержимое папки `app/`**.
2. Папка `.github` скрытая. Если при загрузке она не появилась, нажмите *Add file → Create new file*, в имени файла напишите `.github/workflows/build-apk.yml` и вставьте содержимое файла `app/.github/workflows/build-apk.yml` из архива.
3. Откройте вкладку **Actions → Сборка APK → Run workflow**.
4. Ждите. **Первая сборка занимает примерно 20–40 минут** (скачиваются Android SDK/NDK и компилируется Python). Следующие быстрее.
5. Когда появится зелёная галочка, откройте запуск и внизу в разделе **Artifacts** скачайте `medicare-apk`. Внутри zip лежит файл `.apk`.
6. Если красный крестик: откройте запуск, раскройте шаг **Собрать APK**, скопируйте последние ~50 строк лога и пришлите мне.

Это **debug-APK**: он ставится на любой телефон и подходит для показа. Для Google Play нужна отдельная подготовка (подпись, формат AAB, актуальный target API).

## 6. Установка и проверка на телефоне

1. Перенесите `.apk` на телефон и откройте его. Android попросит разрешить установку из этого источника.
2. При первом запуске разрешите уведомления.
3. Проверьте по порядку:
   - [ ] Онбординг проходится, главный экран открывается.
   - [ ] Добавьте лекарство на время «через 3 минуты». Закройте приложение. Придёт уведомление.
   - [ ] Перезагрузите телефон. Напоминание на следующее время всё равно должно прийти.
   - [ ] Раздел «Помощник»: напишите «Привет». Появится запрос согласия, затем ответ. Если «ошибка сети» — проверьте `/health` (раздел 2) и `API_URL` (раздел 3).
   - [ ] Напишите «у меня боль в груди»: подсказка про 112 появляется сразу, даже в авиарежиме.
   - [ ] Напишите «Добавь аспирин 100 мг утром на 5 дней»: помощник предложит карточку, лекарство добавится **только после вашего подтверждения**.
   - [ ] Профиль → «Удалить мои данные» очищает всё.
4. На Xiaomi, Huawei, Samsung и других оболочках с агрессивной экономией батареи зайдите в настройки приложения и отключите для MediCare оптимизацию батареи, иначе система может «усыплять» напоминания.

## 7. Частые проблемы

| Симптом | Причина и решение |
|---|---|
| Помощник: «сервер не настроен» | В `config.py` пусто `API_URL`. Впишите и пересоберите APK. |
| Помощник: ошибка доступа | На сервере задан `APP_KEY`, а в приложении ключа нет (на телефоне нет переменных окружения). Удалите `APP_KEY` на Railway или впишите тот же ключ в `APP_KEY` в `config.py`. |
| Помощник: ошибка сети | Сервер спит/упал или неверный адрес. Откройте `/health` в браузере. |
| Помощник: «слишком много запросов» | Сработал лимит (6/мин, 100/день на телефон). Подождите. |
| Деплой на Railway красный | Не задан `SERVER_SECRET` (нужно ≥ 24 символов). |
| Если подключили Volume и «permission denied» | Добавьте переменную `RAILWAY_RUN_UID=0`. |
| Белый квадрат вместо значка в уведомлении | Исправлено в этой версии (системный значок). |

## 8. Что честно сказать работодателю

- Это **демонстрационная версия**: она не медицинское изделие и не заменяет врача (в приложении есть соответствующие предупреждения).
- Справочник из 16 препаратов и **армянские тексты не проверены врачом и носителем языка**. До реального использования нужна проверка.
- Текст переписки и список лекарств уходят в Anthropic API. Для реального запуска нужна политика конфиденциальности и согласие пользователя (согласие в приложении уже есть).
- Регистрация устройств без логина: защита держится на лимитах и на лимите расходов в консоли Anthropic. Для продакшена нужна проверка подлинности приложения (например, Play Integrity).
